# PlayCanvas — 3D Benchmark

Часть проекта [3D Engine Benchmark](../README.md).

## Результаты

| Метрика | Значение |
|---------|----------|
| Средний FPS | 40.6 |
| Макс FPS | 43.7 |
| Мин FPS | 26.9 |
| Стабильность | 61.7% |
| CPU (avg) | 67.6% |
| GPU (avg) | 31% |
| RAM (max) | 35.6% |
| VRAM | 10.7% |
| Draw calls | 4780 |

## Особенности

- Баланс между FPS и стабильностью — лучший компромисс
- Стабильность почти вдвое выше, чем у Three.js
- Чуть выше потребление RAM (35.6%)
- Движок MIT, редактор проприетарный

## Запуск

```bash
npm install
npm run dev
```

## Стек

- PlayCanvas 2.x
- Vite
- WebGL2
