# Babylon.js — 3D Benchmark

Часть проекта [3D Engine Benchmark](../README.md).

## Результаты

| Метрика | Значение |
|---------|----------|
| Средний FPS | 26.7 |
| Макс FPS | 28.6 |
| Мин FPS | 20.8 |
| Стабильность | 72.7% |
| CPU (avg) | 62.9% |
| GPU (avg) | 36.6% |
| RAM (max) | 37.5% |
| VRAM | 12.1% |
| Draw calls | 4780 |

## Особенности

- Лучшая стабильность (72.7%) среди трёх движков
- Самый низкий средний FPS (26.7) — ограничен пайплайном рендера
- Равномерное распределение нагрузки: CPU 62.9% / GPU 36.6%
- Apache 2.0 — требует сохранения NOTICE
