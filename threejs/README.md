# Three.js — 3D Benchmark

Часть проекта [3D Engine Benchmark](../README.md).

## Результаты

| Метрика | Значение |
|---------|----------|
| Средний FPS | 43.8 |
| Макс FPS | 48.0 |
| Мин FPS | 15.5 |
| Стабильность | 32% |
| CPU (avg) | 71.9% |
| GPU (avg) | 32% |
| RAM (max) | 32.8% |
| VRAM | 10.6% |
| Draw calls | 4780 |

## Особенности

- Лучший средний FPS (43.8) среди трёх движков
- Самая низкая стабильность (32%) — просадки до 15.5 FPS
- CPU-bound: CPU упирается в 100%, GPU недогружен (около 32%)
- MIT — свободное коммерческое использование

## Запуск

```bash
npm install
npm run dev
```
